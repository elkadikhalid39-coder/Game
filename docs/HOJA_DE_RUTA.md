# Hoja de ruta

Cada fase termina con la prueba automática en verde, un enlace para probar y un resumen de lo que cambió y de lo que queda por decidir. Las semanas son orientativas.

## Fase 0: depuración y bases (hecha)

- [x] Bases del producto en [PRODUCTO.md](PRODUCTO.md).
- [x] Fuera el modo niños, el aprendizaje de otros idiomas, las vidas, las rachas y los puntos.
- [x] Los errores de una lección vuelven al final de esa misma lección.
- [x] Código, pruebas y documentación limpios.

## Fase 1: estructura técnica (semana 1)

- [ ] Proyecto con módulos y Vite, sin framework.
- [ ] Datos de contenido en archivos separados del código.
- [ ] Funciona sin internet (PWA), con las fuentes tipográficas incluidas.
- [ ] Registro de datos legales con fuente, estado y fecha de comprobación, más una comprobación automática que falla si falta algo.
- [ ] Migración del progreso guardado.

## Fase 2: curso A1 (semanas 2 y 3)

- [ ] Motor de lecciones según los principios:
  - botón lento;
  - «No puedo escuchar ahora» y «Saltar»;
  - ejercicio de escribir con corrección tolerante;
  - práctica final de premio;
  - cabecera fija con la unidad.
- [ ] Objetivo «Ya sé…» en cada unidad y pantalla de progreso por objetivos.
- [ ] Unidades nuevas: Trabajo, Vivienda y Papeleo.
- [ ] Revisión de las unidades actuales con el Plan Curricular del Instituto Cervantes (pendiente de leer).

## Fase 3: pase de Nacionalidad (semanas 3 a 5)

- [ ] «Mi trámite»: preguntas → lista de comprobación personalizada, con cada punto enlazado a su fuente.
- [ ] CCSE: temario por tareas, banco de preguntas original (primero 60, después 300 con la proporción del manual), simulacro de 25 preguntas en 45 minutos, apto con 15.
- [ ] DELE A2: lectura, auditiva, escrita y oral, con simulacros, rúbricas, cronómetro y el día del examen.
- [ ] Pantalla de compra simulada y muestra gratuita (el pago real va en la fase 5).

## Fase 4: pase de Universidad (semanas 5 a 7)

- [ ] «Mi ruta a la universidad».
- [ ] Fichas de materias PCE: primero las 5 ya verificadas, después el resto.
- [ ] Redacción académica en español.
- [ ] Simulacros cronometrados.
- [ ] Nota de acceso solo como estimación, con aviso.

## Fase 5: calidad y lanzamiento (semanas 7 y 8)

- [ ] Revisión por especialistas (profesor de español acreditado y profesional jurídico) y paso de *borrador* a *publicado*.
- [ ] Voces de calidad para todo el contenido.
- [ ] Revisión de traducciones por nativos.
- [ ] Accesibilidad y privacidad (edad mínima confirmada en la norma).
- [ ] Empaquetado para Android e iOS y pagos.
- [ ] Beta cerrada con usuarios reales (una ONG o una escuela de adultos).

## Después del lanzamiento

- Nivel 0 de alfabetización (LASLLIAM).
- Unidades A2 completas.
- Micrófono para practicar la pronunciación.
- Licencias para entidades.
